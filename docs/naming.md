# Naming Shortlist

The product needs a name that is not ColdDesert-branded.

## Direction

Tone: precise, athletic, control-system, not bro-fitness.
Avoid: generic AI coach names, gimmicky animal names, anything that sounds like a supplement brand.

## Shortlist

1. AERION
   - Aerobic + system/control feel
   - Clean, premium, short

2. PACECRAFT
   - Practical, endurance-specific
   - Slightly broader than cycling

3. RACECRAFT
   - Strong fit for fixed-race optimization
   - More tactical, less wellness

4. AEROSTACK
   - Modular, technical
   - More builder/product feel

5. FORMSTATE
   - Focus on fitness/fatigue/form state
   - Calm and analytical

6. STEADYCRAFT
   - Aerobic base / consistency
   - Less race-focused

7. ENGINE ROOM
   - Strong metaphor
   - Possibly too generic

8. VELOFORM
   - Cycling-leaning
   - Less suitable if running remains important

## Current recommendation

Use `AERION` as temporary codename.
Product folder remains `endurance-engine` until Dennis chooses final name.
